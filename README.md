# truber

Freight marketplace. This checkout contains the published API contract and the first backend slice.

- Contract: [`api/openapi.yaml`](api/openapi.yaml) (v0.2.0, byte-for-byte published file)
- Backend: [`backend/README.md`](backend/README.md) (NestJS auth, companies, and loads)

Booking, payments, matching, GPS, and live provider calls are not implemented.
